## 一、游客模式（未登录）

- [ ] 页面正常加载，无报错

## 三、注册第二个账号，验证数据隔离

先点右上角「退出」，再注册：

```text
用户名：test_b
密码：test123456
显示名：B 同学
```

确认：

- [ ] B 同学登录后，短视频脚本里**没有** A 同学新增的脚本
- [ ] B 同学看到的是自己的一套初始示例数据
- [ ] 两个账号的脚本数量各自独立

这是本轮最核心的验证点：**数据按用户隔离**。

## 五、接口级验证（可选，命令行）

在 Mac 终端执行：

```bash
curl --noproxy '*' http://127.0.0.1:8000/api/health
```

注册并拿到 token：

```bash
curl --noproxy '*' -X POST http://127.0.0.1:8000/api/auth/register \
  -H 'Content-Type: application/json' \
  -d '{"username":"api_test","password":"test123456","display_name":"接口测试"}'
```

未登录访问受保护接口，应返回 401：

```bash
curl --noproxy '*' -i -X POST http://127.0.0.1:8000/api/sync/import
```

## 七、已知限制

1. **绑定视频号账号的界面还没做**  
   目前只有 API：`POST /api/channels`。前端入口待加。

2. **删除素材只删本地**  
   素材列表的「移除」目前只改前端状态，没有调删除接口。

3. **视频号抓取需要扫码**  
   `channels.weixin.qq.com` 会跳登录页，需要你本人扫码。

4. **静态部署环境没有登录按钮**  
   如果访问的是静态快照版本（无后端），右上角会显示「演示环境 · 静态数据」，注册登录不可用，这是预期行为。
