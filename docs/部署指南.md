# 北极星 NorthStar · 云端部署操作指南（从零到上线）

> 适用对象：第一次部署个人产品的操作者。每一步都给出「在哪点、填什么、花多少钱」。
> 目标架构：域名 → 云服务器（Nginx）→ 前端静态页 + /api 反代 → FastAPI + SQLite。

---

## 总览：要买两样东西

| 要买 | 作用 | 推荐 | 年费参考 |
|---|---|---|---|
| 云服务器 | 跑产品（前端页面 + 后端 API + 数据库） | 腾讯云轻量应用服务器 2C2G | ¥60-100/年（新人价） |
| 域名 | 让别人用网址访问（如 northstar.app） | 腾讯云 DNSPod 注册 | .com ¥55-75/年，.cn ¥29-39/年 |

**建议全部在腾讯云一家买**：域名 + 服务器 + 免费 SSL 证书在同一控制台，少一次账号打通。阿里云流程几乎一样（ECS 突发性能型 t6 + 万网域名），下文以腾讯云为主，差异处会标注。

---

## 第一步：买云服务器（约 10 分钟）

1. 打开腾讯云轻量应用服务器购买页：`https://buy.cloud.tencent.com/lighthouse`
2. 配置选择：
   - 地域：**广州/上海**（离你和你的用户近即可）
   - 镜像：**Ubuntu 22.04 LTS**（不要选 Windows）
   - 套餐：**2核 2G 4M带宽** 起步（个人产品足够，不够可后升配）
3. 付费后进入控制台 `https://console.cloud.tencent.com/lighthouse`，能看到服务器**公网 IP**（如 `43.x.x.x`）
4. 在「防火墙」里确认放行：**22（SSH）、80（HTTP）、443（HTTPS）**——轻量默认已放行 22/80/443，没有就手动加
5. 本地终端测试登录（Mac 自带终端）：
   ```bash
   ssh ubuntu@你的公网IP    # 密码在控制台「重置密码」里设置；也可用控制台的「免密登录」
   ```

> 阿里云对应物：ECS「突发性能实例 t6」或轻量应用服务器，控制台在 `ecs.console.aliyun.com`，安全组里放行 80/443。

## 第二步：买域名并解析到服务器（约 10 分钟 + 等生效）

1. 打开 DNSPod 域名注册：`https://dnspod.cloud.tencent.com/`（腾讯云账号直接登录）
2. 搜一个想要的域名，例如 `northstar.run` / `beijixing.cn`，加入购物车付款
3. 买完后进「我的域名」→ 点域名 →「DNS 解析」→ 添加记录：
   - 主机记录：`@`（裸域名）和 `www` 各加一条
   - 记录类型：**A**
   - 记录值：**你的服务器公网 IP**
4. 等 5-30 分钟生效，本地验证：
   ```bash
   ping 你的域名    # 返回你的服务器 IP 即解析成功
   ```

> ⚠️ 中国大陆服务器 + 域名对外提供网站服务，理论上需要 **ICP 备案**（腾讯云控制台可免费提交，约 3-10 个工作日）。**不想备案的两条路**：① 买腾讯云「中国香港」地域的轻量服务器（免备案，国内访问稍慢一点点）；② 先只用 IP 访问内测。

## 第三步：把代码传上服务器（约 5 分钟）

在**本地**项目目录执行（把整个 northstar 目录传上去）：

```bash
cd /Users/maggieewu/WorkBuddy/2026-08-28-23-40-33
scp -r northstar ubuntu@你的公网IP:/opt/
# 如果 /opt 需要权限：先 ssh 上去 sudo mkdir -p /opt/northstar && sudo chown ubuntu:ubuntu /opt/northstar
```

前端**先在本地构建好**（服务器不用装 Node）：

```bash
cd northstar/frontend && npm run build   # 产出 dist/，会一起被 scp 传上去
```

## 第四步：服务器上启动（约 10 分钟，脚本一键）

SSH 到服务器后：

```bash
cd /opt/northstar/backend
cp .env.example .env        # 先不填也能跑（降级模式），之后填了重启即激活
bash deploy/deploy.sh       # 自动：装 Python 依赖 → 建 venv → 配 Nginx → 注册 systemd 开机自启
```

或者用 Docker（服务器需先 `curl -fsSL https://get.docker.com | bash`）：

```bash
cd /opt/northstar/backend
docker compose -f deploy/docker-compose.yml up -d --build
```

验证（在服务器上）：

```bash
curl http://127.0.0.1:8000/api/health     # 应返回 {"status":"ok"}
curl http://127.0.0.1/api/dashboard       # 经 Nginx 反代，应返回 JSON
```

此时浏览器打开 `http://你的域名` 就能看到产品了（HTTP 版）。

## 第五步：HTTPS（约 10 分钟，免费）

1. 腾讯云控制台搜「SSL 证书」→「免费证书」→ 申请（域名型 DV，填你的域名）
2. 审核通过后下载 **Nginx 格式**证书（两个文件：`xxx.crt` 和 `xxx.key`）
3. 上传到服务器 `/etc/nginx/ssl/`（没有就 mkdir）
4. 改 `/etc/nginx/sites-available/northstar`（或 `deploy/nginx.conf` 的参考），把 80 端口的 server 改成：

```nginx
server {
    listen 443 ssl;
    server_name 你的域名;
    ssl_certificate     /etc/nginx/ssl/xxx.crt;
    ssl_certificate_key /etc/nginx/ssl/xxx.key;

    root /opt/northstar/frontend/dist;
    index index.html;

    location /api/ { proxy_pass http://127.0.0.1:8000/api/; }
    location /    { try_files $uri $uri/ /index.html; }
}
server {                          # 80 跳 443
    listen 80;
    server_name 你的域名;
    return 301 https://$host$request_uri;
}
```

5. `sudo nginx -t && sudo systemctl reload nginx`
6. 浏览器打开 `https://你的域名`，带锁即完成

> 更省事的替代：`sudo apt install certbot python3-certbot-nginx && sudo certbot --nginx -d 你的域名`，Let's Encrypt 自动签发 + 自动改配置 + 自动续期。

## 第六步：日常运维（常用 5 条命令）

```bash
journalctl -u northstar -f          # 看后端实时日志
sudo systemctl restart northstar    # 改了 .env / 代码后重启后端
cd /opt/northstar && git pull       #（如果用了 Git）更新代码后重跑 deploy.sh
df -h                               # 看磁盘（SQLite 和素材占空间）
sudo certbot renew                  # 证书续期（certbot 方案会自动跑）
```

更新代码的日常流程：**本地改 → npm run build → scp 覆盖 /opt/northstar → ssh 重启服务**。

## 激活清单（上线后想开真能力时再填）

在服务器 `/opt/northstar/backend/.env` 填入，然后 `sudo systemctl restart northstar`：

| 能力 | 变量 | 不填时 |
|---|---|---|
| Cue 真实 AI 问答 | `HUNYUAN_API_KEY` | 前端关键词规则兜底 |
| 飞书知识库直连 | `FEISHU_APP_ID` / `FEISHU_APP_SECRET` | 种子数据兜底 |
| 登录态签名 | `JWT_SECRET` | 随机密钥（重启需重登） |
| 视频号自动抓取 | 无需配置，首次扫码 | 登录态约 7 天，可用 CSV 导入兜底 |
