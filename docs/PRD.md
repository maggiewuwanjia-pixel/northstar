# 北极星 NorthStar · 产品需求文档（PRD）

> 版本：v1.0（2026-09-01） · 状态：可交互原型已完成
> 产品一句话：**视频号经营者的 AI 副驾驶** —— 盯住那一颗北极星指标，让 AI 助手 Cue 告诉你下一步做什么。

---

## 1. 产品定位与目标用户

| 项 | 内容 |
|---|---|
| 产品名 | 北极星 NorthStar |
| AI 助手 | Cue（"cue 下一步"） |
| 目标用户 | 视频号教育类中小博主（10-50w 粉），案例账号：清华优优（22.4w 粉） |
| 核心问题 | 视频号助手后台只有数据没有结论；创作者不知道"下一步做什么" |
| 产品解法 | 数据 → 结论 → 行动：把后台数据、脚本库、直播复盘、对标监控收敛成一个工作台，AI 直接给出行动建议并一键落地 |

## 2. 设计系统（UI v3）

- 基底：暖白 #FAFAF8 + 白卡片 + 1px 细边 #E9E9E5；近黑 #191919 文字、#1A1A1A 主按钮
- 磨砂：侧栏 / 顶栏 / Copilot 面板 半透明 + backdrop-filter blur（苹果风）
- 点缀色：微信绿 #07C160 仅用于进度条、状态点、语义标签
- Hero：北极星指标卡与知识库"知识总览"用墨绿深色面板 #0E1F16
- 参考：Gumloop（极简黑白灰）、LocalCan（墨绿深色 + 网格线）、macOS 磨砂
- 原则：**不允许出现空数据/空图片占位**——所有封面、头像、截图均为真实素材

## 3. 信息架构（一级导航 7 项）

```
北极星 NorthStar
├── 经营看板 dashboard        —— 结论先行：3 行动建议 → 北极星 → KPI → 趋势 → 画像 → 排期 → TOP 内容
├── 知识库 wiki               —— 个人空间 / 团队空间，文件详情四视图：原始文件(chunk) / AI摘要 / AI知识库 / 知识图谱
├── 短视频脚本 scripts        —— 脚本卡片工作台（封面 + 标签 + 来源）
├── 直播复盘 live-summary     —— 左：场次列表；右：数据卡 + 后台截图 + 画面复盘 + 脚本复盘 + AI 抽帧
├── 直播脚本 live-script      —— 三套模板（标准场 / 高成交场 / 节点场）
├── 对标账号 bench            —— 监控中 / AI 发现 / 爆款抓取
└── 素材库 library            —— 全局拖拽入口，链接/文件自动归类
常驻：右侧 Copilot 面板（Cue）—— 全页面可对话，回答带来源引用，可一键"落地"到脚本
```

## 4. 页面详述与跳转逻辑

### 4.1 经营看板 `/dashboard`
- 元素：3 张行动卡（本周该做什么）→ 北极星卡（涨粉/GMV/播放 三键切换，墨绿 hero）→ 4 KPI → 7 日趋势（图表/列表切换）→ 3 画像卡（年龄/性别/地域）→ 4 周甘特排期 → 内容表现 TOP（6 张真实封面）
- 跳转：
  - 「查看全部」→ 提示（演示）
  - 点视频卡 → toast（演示）
  - 北极星三键切换 → 就地刷新数值与目标进度

### 4.2 知识库 `/wiki`（两级结构）
- 列表层：左侧空间树（个人空间：我的知识库/拆脚本记录；团队空间：短视频脚本库/直播复盘库/直播脚本库/对标监控库）+ 右侧文件行（来源 tag / 更新时间 / 状态 pill）
- 详情层：点文件进入，顶部 tab：**原始文件**（chunk 卡片：#序号 / 字数 / 已向量化）｜**AI 摘要**（知识总览 hero + 概览 + 主题分区卡）｜**AI 知识库**（索引 / 摘要 / 实体云）｜**知识图谱**（SVG 三层放射图：摘要/实体/概念 + 图例 + 节点数）
- 跳转：
  - 点文件行 → 详情层；「‹」返回列表
  - 「拆脚本」→ 加入短视频脚本工作台（不跳页，toast 确认）
  - 「打开原文 ↗」→ 新窗口打开飞书文档
  - 「AI 整理」→ 触发整理（演示）

### 4.3 短视频脚本 `/scripts`
- 元素：脚本卡片网格（真实封面 + 时长 + 标签 + 来源）
- 跳转：无二级页；卡片点击 toast（演示）

### 4.4 直播复盘 `/live-summary`
- 左：8 场真实场次列表（封面缩略图 + 时长/观看/峰值/热度/成交）
- 右：选中场的完整复盘 —— 数据卡 → **视频号助手后台真实截图**（11-15 场）→ 画面复盘（光线/服装/手势/布场）→ 脚本复盘 → AI 抽帧区（"导入回放视频"触发抽帧动画演示）
- 跳转：点左侧场次行 → 右侧就地切换

### 4.5 直播脚本 `/live-script`
- 元素：模板卡片（名称 + 日期 + 时长 pill + 结构说明）
- 跳转：无

### 4.6 对标账号 `/bench`
- 三段：监控中（真实头像 + 粉丝数 + 健康度 pill）→ AI 发现 → 爆款抓取（真实封面 + 点赞 + 来源账号）
- 跳转：
  - 「+ 添加对标」→ 全局 modal（名称/链接 + 备注）
  - 「对比」「+ 监控」→ toast（演示）
  - 「拆脚本」→ 加入短视频脚本（封面随条目带入）

### 4.7 素材库 `/library`
- 元素：拖拽区（整页任意位置也可拖）+ 条目列表（飞书/文件/链接 icon + 元信息）
- 跳转：拖入链接 → 按域名自动归类（飞书→知识库、视频号→对标、公众号→知识库、其他→素材库）并 toast

### 4.8 Copilot（Cue，常驻右侧）
- 元素：对话流（引用 chip、落地按钮）+ 快捷问题 pill + 输入框
- 跳转：「落地」类按钮 → 加入脚本并跳转到对应工作台（`landScript`）

### 4.9 全局组件
- 登录弹层（登录/注册 tab、游客模式）、toast（顶部黑 pill）、modal（磨砂遮罩 + 表单）

## 5. 数据流

```
视频号助手后台 ──(Playwright 扫码抓取 / CSV 导入兜底)──┐
飞书文档（脚本/复盘/直播脚本）──(tenant_token + docx API)─┤
                                                       ├─→ FastAPI + SQLite ─→ 9 组 REST API ─→ Vue3 SPA
对标账号（手工录入 + 监控）─────────────────────────────┘        │
ima / 混元（待激活，.env 填 key 即通）────────────────→ Cue 问答 ──┘
静态兜底：dist 内置 data.json 快照，无后端时自动降级
```

## 6. 部署形态

- 前端：Vite 构建静态 dist（可独立托管，内置数据快照）
- 后端：FastAPI（uvicorn :8000）+ SQLite 单文件
- 云端：腾讯云轻量应用服务器 + Nginx 反代 + 域名 + HTTPS（详见《部署指南》）
